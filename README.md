# Análisis de ventas

## Datos y preparación

Fuente: [https://github.com/ANAPBORGES/tableau-sales-profitability-dashboard/blob/main/data/superstore.csv](https://www.tableau.com/learn/tutorials/on-demand/getting-started-part3)

La muestra contiene 1.800 registros seleccionados a lo largo de las 9.994 líneas del original. Son datos de una tienda ficticia de Estados Unidos entre 2015 y 2018. Los importes están en dólares.



## Resultados

|Indicador|Resultado|
|-|-:|
|Ventas totales|$385.665|
|Beneficio total|$49.623|
|Margen de beneficio|12,9 %|

**Material de oficina** tuvo las mayores ventas ($137.302). **Tecnología** obtuvo el mayor beneficio ($26.082). **Muebles** vendió $122.209 y obtuvo $1.390 de beneficio, un margen aproximado del 1,1 %.

**2018** fue el año con más ventas ($126.205) y beneficio ($15.999). Las ventas subieron cada año en la muestra.



## Conclusión

Conviene revisar los productos de Muebles por su bajo margen. Estos resultados describen la muestra, pero no explican la causa.
